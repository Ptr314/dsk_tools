# dsk_tools

dsk_tools &mdash; библиотека для работы с образами дискет ретро-компьютеров. На основе библитеки создана программа **[DISK Commander](https://github.com/Ptr314/dsk_commander)**. Подробнее смотрите на соответствующей странице по ссылке.

Для простых операций с дисками подготовлена утилита командной строки **fddconv**, которую можно скачать на странице [Releases](https://github.com/Ptr314/dsk_tools/releases).

**fddconv** используется следующим образом:

```bash
>fddconv INPUT_FILE parameters and commands
```

Параметры могут быть следующими:
```
    -f, --input_format DDD:FFF  Тип входного файла (не обязательно)
    -o, --output OUT_FILE       Выходной файл (обязателен, кроме команд ls и extract)
    -m, --volume XX             Volume ID* (не обязательно)
    -b, --binary                Сохранять файлы в исходном виде (см. команду extract)
    -v, --verbose               Выводить подробную информацию
    -h, --help                  Вывод помощи
```

Примечания:
- Volume ID может быть десятичным (напр. 254) или 16-ричным (напр. $FE).

Команды для работы с образом:
```
    -l, --ls                    Вывести список файлов
    -a, --add FILE              Добавить файл (допускается несколько раз)
    -d, --delete FILE           Удалить файл (допускается несколько раз)
    -e, --extract FILE          Извлечь файл* (допускается несколько раз)
```

Примечание для **-e**: с дисков Apple/Агат DOS файлы по умолчанию будут сохраняться в формате FIL. Чтобы сохранить файл в исходном виде, нужно добавить опцию -b (--binary).

Если не указана ни одна команда, файл будет сконвертирован без изменений.

Фомат диска в общем случае можно не указывать, он будет определяться автоматически. Если это по какой-то причине не удается, его можно задать явно в виде DDD:FFF, где DDD &ndash; тип диска, а FFF &ndash; тип файловой системы. Значения следующие:


```
DDD:    a140 (Apple/Агат 140k)
        a840 (Агат 840k)
        i360i, i360s (Ириша 360 Кб с чередованием сторон / без чередования
        korvet (Корвет 800k CP/M)
        orion (Орион-128/ПК8000 800 Кб CP/M)
        vector (Вектор-06Ц 800+ Кб CP/M)
        pc360, pc720, pc1200, pc1440 (IBM PC 360-1.44)
                
FFF:    dos33 (Apple/Агат DOS)
        sos (Sprite OS)
        cpm, cpm-do, cpm-po (CP/M raw, DOS sectors, ProDOS sectors)
        fat (MS-DOS FAT)
```

Формат выходного файла выбирается в соответствии с расширением. Доступны следующие варианты:

- 140к: dsk, nib, nic.
- 840к: dsk, hfe.

Для форматов nib, nic, hfe можно задать Volume ID.

### Примеры использования

Вывести список файлов на диске:

```bash
# Автоопределение формата:
>fddconv IKP7_140.DSK -l

# Формат Вектор-06Ц:
>fddconv disk.fdd -f vector -l
```

Конвертировать в другой формат:

```bash
>fddconv IKP7_140.DSK -o IKP7_140.nib
```

Добавить файлы к образу:

```bash
>fddconv disk.fdd -f vector -o disk1.fdd -a game.com -a game.dat
```

Добавить файлы и результат сохранить в формате HFE с Volume ID = $AF:

```bash
>fddconv INIT840.DSK -o EXE840.hfe -a exec.fil -a data.fil -m $AF
```

Удалить файл и сохранить образ под другим именем:

```bash
>fddconv EXE840.DSK -o EXE840_del.DSK -d GAME
```

Извлечь два файла и сохранить их в двоичном формате:

```bash
>fddconv IKP7_140.DSK -e hello -e link -b
```

Указать тип входного образа, если он не определяется автоматически, затем вывести список файлов с подробной информацией по ходу работы:

```bash
>fddconv IKP7_140.DSK -f a140:dos33 -l -v
```


## aim2hfe

**aim2hfe** &mdash; отдельная утилита для прямой конвертации физических образов Агата AIM (840 Кб) в формат HxC HFE (v2), пригодный для записи на эмулятор дисковода. В отличие от `fddconv`, образ не разбирается на сектора: дорожка перекодируется целиком, включая GAP'ы, метки синхронизации (DESYNC) и нестандартные записи, поэтому сохраняется защита от копирования.

```bash
>aim2hfe INPUT_FILE [-o OUT_FILE] [-v]
```

Параметры:
```
    -o, --output OUT_FILE       Выходной файл (по умолчанию имя входного с расширением .hfe)
    -v, --verbose               Выводить подробную информацию
    -h, --help                  Вывод помощи
```

Пример:

```bash
>aim2hfe JOKER.aim -o JOKER.hfe
```

Алгоритм конвертации повторяет скрипт `agath-aim-to-hfe.pl` Александра Капитаненко (PortaOne, Inc.). Дополнительно поддерживаются образы, в которых часть GAP'а записана нулями вместо $AA (некоторые дампы не дочитывают GAP до конца): такие ячейки считаются частью GAP'а и восстанавливаются в $AA.
