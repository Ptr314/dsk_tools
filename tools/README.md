# tools

Вспомогательные скрипты для разбора образов. Нужен Python 3 (только стандартная
библиотека, сторонних пакетов нет).

## Разбор AIM (Агат, 840 Кб)

Дорожка AIM — это 6464 ячейки по два байта: байт данных и команда AIM. Дамп чуть
длиннее одного оборота, поэтому дорожка разбирается как кольцо: последнее поле
переходит через начало, а первые ячейки могут быть повторным чтением последних.

| Скрипт | Назначение |
|---|---|
| `aim_scan.py <file.aim> ...` | Полный разбор структуры и отчёт обо всём, что не укладывается в стандартную последовательность: эпилоги, контрольные суммы, дубли и пропуски секторов, DESYNC не на месте, неизвестные команды AIM, данные в GAP'ах |
| `aim_order.py <file.aim> [дорожка ...]` | Физический порядок секторов. Без указания дорожек — сводка: сколько дорожек являются простым поворотом 0…20 (это норма, дамп начинается с произвольного угла), а сколько нет |
| `aim_extract.py <file.aim> <out.dsk>` | Собирает raw-образ 160×21×256, раскладывая секторы по номеру из заголовка. Независимая от библиотеки реализация — удобна как эталон при проверке `LoaderAIM` и конвертации |
| `aim_dump.py <file.aim> <дорожка> [ячейка] [сколько]` | Дамп ячеек дорожки со сжатием повторов: `DD[/CC][*N]` |

Разбор дорожки на поля общий для всех четырёх и лежит в `aim_common.py`.

Результаты прогона по коллекции образов — в [aim-anomalies.md](aim-anomalies.md).

Пример проверки того, что конвертация ничего не теряет:

```bash
python tools/aim_extract.py disk.aim ref.dsk   # содержимое исходного AIM
aim2hfe disk.aim -o disk.hfe
fddconv disk.hfe -o test.dsk                   # содержимое после конвертации
cmp ref.dsk test.dsk
```
